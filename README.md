## Overview

Welcome to Group 14's Find-A-Dog, a web application crafted with Node.js, Bootstrap, and MongoDB. Our platform is designed to assist users in finding their ideal furry companions. Whether you're eager to adopt a dog or simply want to explore a gallery of adorable pups, Find-A-Dog is here to make the process easy and enjoyable.

## Features

- **Search and Filter**: Effortlessly find dogs based on various criteria, including breed, size, age, and location.

- **Detailed Profiles**: Each dog has a comprehensive profile featuring information about their personality, habits, and background.

- **Adoption Process**: Gain insights into the adoption process, including application details, fees, and what to expect during the adoption journey.

- **Responsive Design**: Our application is meticulously designed with Bootstrap, ensuring a seamless and enjoyable experience across various devices and screen sizes.

- **User Authentication**: Enjoy the convenience of user accounts with authentication, allowing you to track your favorite dogs and save your searches.

## Prerequisites

Before getting started, make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/)

## Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/CEN4010-Fall2023-Prin-Soft-Eng/cen4010-prin-soft-eng-final-project-001-group-14
   ```

2. **Navigate to the project directory:**

   ```bash
   cd find-a-dog
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Run the application:**

   ```bash
   npm start
   ```

   The application will be accessible at [http://localhost:5678](http://localhost:5678).
